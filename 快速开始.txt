========================================
Shop 工具合集 - 打包为 EXE 快速指南
========================================

【最简单的方法 - 推荐小白用户】

方法一：双击运行（最简单）
--------------------------
1. 双击 "一键打包.bat" 文件
2. 等待打包完成（可能需要几分钟）
3. 在 dist 文件夹中找到 "Shop工具合集.exe"
4. 完成！

方法二：使用 Python 脚本
------------------------
1. 打开命令提示符（CMD）
2. 进入项目文件夹
3. 输入命令：python build_exe.py
4. 等待完成

【打包完成后】

1. 找到 dist/Shop工具合集.exe
2. 这个 exe 文件可以在任何 Windows 电脑上运行
3. 无需安装 Python 或其他依赖
4. 双击即可使用

【注意事项】

✓ 首次运行可能需要几秒钟启动
✓ 杀毒软件可能误报（这是误报，添加信任即可）
✓ exe 文件可能较大（100-200MB），这是正常的
✓ 确保电脑已安装 Chrome 浏览器（程序需要）
