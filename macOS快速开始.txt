========================================
macOS 打包快速指南（M 芯片）
========================================

【前提条件】
-----------
✓ macOS 系统（M1/M2/M3 芯片）
✓ Python 3.8 或更高版本
✓ Chrome 浏览器

【快速打包】
-----------
1. 打开终端（Terminal）
2. 进入项目目录
3. 运行: python build_mac.py
4. 等待完成
5. 在 dist 文件夹找到 Shop工具合集.app

【首次运行】
-----------
如果无法运行，尝试：
1. 右键点击应用 -> 打开
2. 或在终端运行：
   xattr -cr "dist/Shop工具合集.app"

【创建安装包】
--------------
运行: python create_dmg.py
会生成 .dmg 文件，方便分发
