========================================
在 Windows 上打包 macOS 应用的解决方案
========================================

【为什么不能？】
---------------
Windows 无法直接打包 macOS 应用，因为：
- 二进制格式不同（PE vs Mach-O）
- 需要 macOS 系统工具
- PyInstaller 限制

【推荐方案：GitHub Actions（免费）】
------------------------------------
1. 创建 GitHub 仓库
2. 推送代码（我已经创建了工作流文件）
3. 在 GitHub 网页触发构建
4. 下载构建好的 .app 和 .dmg 文件

详细步骤：查看 Windows打包macOS说明.md

【其他方案】
-----------
- 云 Mac 服务（付费）
- 找有 Mac 的朋友帮忙
- 使用虚拟机/SSH

【快速开始】
-----------
1. 如果有 GitHub 账号：
   - 创建仓库
   - 推送代码
   - 在 Actions 页面触发构建
   - 下载结果

2. 如果没有 GitHub 账号：
   - 注册一个（免费）
   - 或使用其他方案

详细说明：Windows打包macOS说明.md
