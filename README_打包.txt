========================================
Shop 工具合集 - 打包为 EXE 文件
========================================

快速开始：
----------
1. 打开命令提示符（CMD）或 PowerShell
2. 进入项目目录
3. 运行: python build_exe.py
4. 等待打包完成
5. 在 dist 文件夹中找到 Shop工具合集.exe

详细说明请查看: 打包说明.md

注意事项：
----------
- 首次运行 exe 可能需要几秒钟启动
- 杀毒软件可能误报，这是正常的，添加信任即可
- exe 文件可能较大（100-200MB），这是正常的
